# 强国有我大思政课案例库

## Vision

建设一个上海大学"强国有我"思政课案例库系统，支持案例的编写、分类、审核和发布全流程管理。

## Current State

- 已有案例库 Web 系统（FastAPI + MongoDB + 纯前端）
- 已有 3 个 Claude Code skill 原型：案例编写(anlibianxie)、主题分类(zhutifenlei)、通用开发(sijiao-case-library)
- 需要完成 alpha 版本发布

## Goals

1. 建立 skills testbench，量化验证 skill 效果
2. 开发审核 skill，支持案例入库前的质量把关
3. 优化现有 skills，确保 alpha 版本可用
